# Rules — Personal Portfolio

## 1. Development Rules

- Gunakan Mobile First.
- Gunakan reusable component.
- Hindari duplicate markup.
- Gunakan static data.
- Jangan membuat component berdasarkan jumlah project.
- Gunakan semantic HTML.
- Gunakan Tailwind CSS untuk styling.

## 2. Component Rules

Component harus memiliki satu tanggung jawab utama.
