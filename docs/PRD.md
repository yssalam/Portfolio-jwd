# PRD — Personal Portfolio

## 1. Overview

Personal Portfolio adalah website pribadi Yoga Subhi Salam untuk menampilkan profil, pendidikan, pengalaman, kemampuan, dan project sebagai web developer.

Portfolio menggunakan static data dan tidak membutuhkan backend atau database.

## 2. Goals

- Menampilkan identitas dan profil secara profesional.
- Menampilkan skills dan pengalaman.
- Menampilkan project yang pernah dibuat.
- Menyediakan detail setiap project.
- Menjadi media pendukung CV dan job application.
- Memiliki desain responsive dengan pendekatan Mobile First.
- Menggunakan reusable component dengan struktur project sederhana.

## 3. Target User

- Recruiter
- HR
- Client
- Developer
- Pengunjung yang ingin melihat project

## 6. Project Requirements

Project harus:
- Responsive.
- Mobile First.
- Menggunakan static data.
- Menggunakan reusable component.
- Tidak melakukan duplikasi markup.
- Memiliki interaction yang jelas.
- Memiliki accessible text dan image.

## 7. Non-Goals

Portfolio tidak membutuhkan:
- Login
- CMS
- Database
- Admin dashboard
- Backend API
- Dynamic content management

## 8. Success Criteria

Portfolio dianggap selesai apabila:
- Semua section utama tersedia.
- Project dapat ditampilkan dari static data.
- Project detail dapat dibuka melalui reusable modal.
- Tampilan responsive.
- Tidak ada duplicate component untuk project.
- Mobile dan desktop mengikuti design yang telah ditentukan.
