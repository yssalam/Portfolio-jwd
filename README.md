# YSSALAM Portfolio

Personal portfolio website built to showcase my projects, skills, experience, and web development journey.

## Live Website

[Visit Portfolio](https://your-portfolio.vercel.app)

## Features

- Responsive design — mobile, tablet, and desktop
- Modern and minimal UI
- Project showcase with project detail modal
- Skills and technologies section
- Experience section
- Contact section
- CV download
- Mobile navigation menu
- Fixed profile background
- Smooth and responsive interactions

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
